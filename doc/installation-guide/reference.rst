.. _image-information:

Image information
-----------------

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - Item
     - Value
   * - Community image
     - | Latest version: ``ghcr.io/frepple/frepple-community:latest``
       | A specific release (recommended!) ``ghcr.io/frepple/frepple-community:VERSION``
   * - Enterprise image
     - | Latest version: ``ghcr.io/frepple/frepple-enterprise:latest``
       | A specific release (recommended!) ``ghcr.io/frepple/frepple-enterprise:VERSION``
   * - Ports
     - | The image exposes only the HTTP port 80.
       | You'll map it to a host port or reach it from a reverse proxy on
         the application network.
   * - Container user
     - | All processes in the container run as the unprivileged user ``frepple``.
       | Do all work in the container as this user. Avoid any temptation to sudo to
         to root.
       | If you need root access (eg to install additional packages), you should
         use a custom dockerfile to perform privileged operations.
   * - Entrypoint
     - | ``/etc/frepple/entrypoint.sh`` is the entrypoint script.
       | You can run without an entrypoint by providing a command line argument.
       | You can add custom initialization commands in the folder ``/etc/frepple/entrypoint.d``.
         Frepple will automatically execute any scripts placed in this folder during container startup.
   * - Processes
     - Four processes are running in the container.

         - | The process supervisor ``supervisord`` manages the other processes.
           | It is configured in ``/etc/frepple/supervisord.conf``

         - | The web server ``nginx`` handles the HTTP requests.
           | It is configured in ``/etc/frepple/nginx.conf``

         - | The application server ``Uvicorn`` generates the web pages. The
           | web application is coded in Python using the Django framework.

         - | The task scheduler ``freppledb.scheduler`` manages background tasks.
           | It provides cron-like scheduling of tasks.


.. _volumes:

Volumes and their content
-------------------------

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Container path
     - Contents and persistence
   * - ``/etc/frepple``
     - | This volume has configuration files and folders. For extra
         security you can mount it as a read-only volume.

       | The content of this folder consists of:

       - | ``/etc/frepple/djangosettings.py``
         | Main application settings, with many settings for the Django
           framework.

       - | ``/etc/frepple/localsettings.py``
         | Optional deployment overrides for djangosettings.py. Use it if you want
           to keep your custom settings separate from the main file.

       - | ``/etc/frepple/license.xml``
         | License key for the Enterrprise Edition.

       - | ``/etc/frepple/entrypoint.sh``
         | Entrypoint script executed during container startup.

       - | ``/etc/frepple/entrypoint.d``
         | Folder for custom initialization scripts executed during container startup.
         | Scripts in this folder are executed in alphabetical order.

       - | ``nginx.conf``
         | Main configuration for the nginx web server.

       - | ``supervisord.conf``
         | Main configuration for the process supervisor. It configures the main processes
           running in the container.

   * - ``/var/log/frepple``
       | This volume contains:

       - | ``/var/log/frepple/*.log``
         | Log files from tasks run from the "execute screen".

       - | ``/var/log/frepple/*.dump``
         | Database dump files generated by the "backup" task in the execution screen.

       - | ``/var/log/frepple/data/<scenario>``
         | Input data files uploaded for the specific scenario.

       - | ``/var/log/frepple/data/<scenario>/export``
         | Exported data files from the specific scenario.

       - | ``/var/log/frepple/uploads``
         | Attachments uploaded by users in the application.

   * - ``/usr/share/frepple/python_packages``
     - | A volumne to store custom Python packages. This folder is added to the Python
         path of the web application and planning engine.
       | Simple customizations can be copied here.
       | For complex customizations, consider creating a derived image with the necessary
         packages.


.. _container_startup_behavior:

Container startup behavior
--------------------------

The entrypoint /etc/frepple/entrypoint.sh of the container goes through the following
steps.

#. On a first start, it replaces the shipped ``SECRET_KEY`` placeholder with a strong
   unique value.
#. If ``POSTGRES_USER``, ``POSTGRES_HOST`` or ``POSTGRES_PORT`` is set,
   waits briefly for PostgreSQL to be ready.
#. On a first start, it creates the configured database.
#. All scenario databases are then migrated to the release of the container image.
   This upgrades your database schema to the new release.
#. On a first start, it loads 2 scenario database with demo data.
#. Some use case require the frepple plan to be loaded in memory as a web service. The
   web service start automatically when users log in. But you can use the environment
   variable ``FREPPLE_AUTOSTART_WEBSERVICE`` to start some web services when the container
   starts.
#. If a command was passed to the container, it will be run at this point.
   The following steps are then not executed any longer.
#. Next, the container executes the scripts available in the folder /etc/frepple/entrypoint.d.
   This is a place to add extra initialization steps.
#. Finally, the container starts its main processes, managed by supervisord.


.. _environment-variables:

Environment variables and settings
----------------------------------

These are variables that can be passed from the container environment.
They can be edited manually in the /etc/frepple/djangosettings.py
or /etc/frepple/localsettings.py files.

Database connection
~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 40 20 40

   * - Variable
     - Default
     - Meaning
   * - ``POSTGRES_HOST``
     - ``localhost``
     - Database hostname. Set explicitly for a separate database container.
   * - ``POSTGRES_PORT``
     - Empty
     - Database port. An empty value uses the PostgreSQL client default,
       normally 5432.
   * - ``POSTGRES_USER``
     - ``frepple``
     - Application database role.
   * - ``POSTGRES_PASSWORD``
     - ``frepple``
     - Application database password. Replace the default.
   * - ``POSTGRES_DB_PREFIX``
     - ``frepple``
     - | Prefix for numbered database names: ``frepple0``, ``frepple1``, etc.
       | Note that changing the database prefix does not rename or move existing databases.
   * - ``POSTGRES_DBNAME``
     - Unset
     - Old, deprecated variable. It is now a mere alias for the POSTGRES_DB_PREFIX.
   * - ``POSTGRES_REPORTING_USER``
     - ``report_role``
     - Restricted database login for custom SQL reports.
   * - ``MIN_NUMBER_OF_SCENARIOS``
     - Lower bound on the number of scenario databases.
   * - ``MAX_NUMBER_OF_SCENARIOS``
     - Upper bound on the number of scenario databases.
   * - ``SCENARIOS``
     - | Number of scenario databases to initialize.
       | Once the database is initialized, we read the number of scenarios from the database.

Web processes and presentation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 40 20 40

   * - Variable
     - Default
     - Meaning
   * - ``FREPPLE_WEBWORKERS``
     - ``4``
     - Number of Uvicorn workers. Only environments with many concurrent users
       may need extra workers.
   * - ``FREPPLE_AUTOSTART_WEBSERVICE``
     - Empty
     - Space-separated scenario identifiers whose planning web services
       should start automatically, for example ``default scenario1``.
   * - ``FREPPLE_TIME_ZONE``
     - Detected local timezone
     - IANA timezone such as ``UTC`` or ``Europe/Brussels``. If detection
       fails, the standard configuration falls back to ``Europe/Brussels``.
   * - ``FREPPLE_THEMES``
     - Bundled theme list
     - Space-separated list of browser themes users can chose from. The default list
       is ``earth grass dark lemon odoo openbravo orange snow strawberry water``.
   * - ``FREPPLE_DEFAULT_THEME``
     - ``earth``
     - Default theme. If not in the enabled list, its first entry is used. User can
       change the theme in their preferences screen.

HTTPS, cookies and embedding
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 40 20 40

   * - Variable
     - Default
     - Meaning
   * - ``FREPPLE_CSRF_TRUSTED_ORIGINS``
     - Empty
     - Space-separated trusted origins, including scheme.
   * - ``FREPPLE_SESSION_COOKIE_SECURE``
     - ``false``
     - Restrict session cookies to HTTPS.
   * - ``FREPPLE_CSRF_COOKIE_SECURE``
     - ``false``
     - Restrict CSRF cookies to HTTPS.
   * - ``FREPPLE_SESSION_COOKIE_SAMESITE``
     - ``lax``
     - SameSite policy for session cookies.
   * - ``FREPPLE_CSRF_COOKIE_SAMESITE``
     - ``lax``
     - SameSite policy for CSRF cookies.
   * - ``FREPPLE_CONTENT_SECURITY_POLICY``
     - ``frame-ancestors 'self'``
     - Content Security Policy header, restricting framing by default.
   * - ``FREPPLE_X_FRAME_OPTIONS``
     - ``SAMEORIGIN``
     - Additional framing restriction.


Email
~~~~~

.. list-table::
   :header-rows: 1
   :widths: 40 20 40

   * - Variable
     - Default
     - Meaning
   * - ``FREPPLE_EMAIL_HOST``
     - Empty (no host configured)
     - SMTP server hostname.
   * - ``FREPPLE_EMAIL_PORT``
     - ``25``
     - SMTP server port.
   * - ``FREPPLE_EMAIL_USE_TLS``
     - ``true``
     - Use STARTTLS for the SMTP connection.
   * - ``FREPPLE_EMAIL_HOST_USER``
     - ``your_email@domain.com``
     - SMTP username; replace the placeholder.
   * - ``FREPPLE_EMAIL_HOST_PASSWORD``
     - Placeholder
     - SMTP password; configure your own credential.
   * - ``FREPPLE_DEFAULT_FROM_EMAIL``
     - ``your_email@domain.com``
     - Default sender address. It is recommended to
       use an alias format for this setting, like ``Alias <your_email@domain.com>``.
   * - ``FREPPLE_SERVER_EMAIL``
     - ``your_email@domain.com``
     - Sender address for server messages.
   * - ``EMAIL_URL_PREFIX``
     - Empty
     - Set it to the to the public URL of your deployment.
       It is used to insert hyperlinks to frepple in emails.

Odoo connector credentials
~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Variable
     - Meaning
   * - ``ODOO_URL``
     - Odoo server URL.
   * - ``ODOO_DB``
     - Odoo database name.
   * - ``ODOO_USER``
     - Odoo login.
   * - ``ODOO_PASSWORD``
     - Odoo credential.
   * - ``ODOO_COMPANY``
     - Company selection.
   * - ``ODOO_SINGLECOMPANY``
     - Connector's single-company option.
   * - ``AUTH_SECRET_KEY``
     - Secret key shared with odoo to allow secure single-signon.

These variables are unset by default. The standard configuration applies
them across scenarios. Configuring the odoo credentials is safer than configuring
them as parameters in the user interface.

Settings without environment variables
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Configure these in Python rather than inventing ``FREPPLE_`` variables:

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - Setting
     - Purpose
   * - ``ALLOWED_HOSTS``
     - Used to restrict access to specific IP-addresses.
   * - ``SECRET_KEY``
     - This key is used internally for cryptographic purposes.
       Keep it secret, long and unique.
   * - ``DEFAULT_USER_GROUP``
     - Default permissions group for new users. If no group is defined, a new
       user is considered a superuser.
   * - ``MAXSTORAGE``
     - Application storage quota in MB; ``None`` means unlimited.
   * - ``MAXTOTALLOGFILESIZE``
     - Total task-log retention limit in MB, default 200.
   * - ``MAXMEMORYSIZE``
     - Planning engine memory size limit in MB; ``None`` means unlimited.
   * - ``MAXCPUTIME``
     - Planning engine CPU-time limit in seconds; ``None`` means unlimited.
